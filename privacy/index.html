English

TalkTooMuch AI is a push-to-talk dictation app. It converts your speech to text entirely on your computer. It also runs a language model (LLM) that you load yourself, also only on your computer: your questions, the answers and any images or text files you add are never sent anywhere.

  1. No data collection. TalkTooMuch AI does not collect, transmit, sell or share any personal data. We (the publisher) never receive your audio, your text or information about how you use the app.
  2. Microphone. Speech is transcribed only while you hold the push-to-talk key or the on-screen talk button. If you turn on “Instant start” in Settings (off by default), the microphone stays open while the app runs so the first syllable is not cut off; only the last 0.3 seconds of audio are kept in memory and are continuously overwritten. Audio is processed only in memory and discarded right after it is converted to text. It is never written to disk and never sent anywhere.
  3. No network access. The app contains no network code. The Microsoft Store package does not request internet access, so the app cannot connect to the internet.
  4. Data stored on your computer. Word lists and settings are stored in the app's folder in your user profile on this computer. Editor text is saved there only if you turn on “Keep editor text” in Settings (off by default); turning it off deletes the saved copy. Before you import settings, a backup of your current settings is saved in this folder (the newest 10 are kept). A settings file you export is saved only where you choose and never contains your editor text. LLM conversations are saved there only if you turn on “Keep conversation” in Settings > LLM (off by default); turning it off deletes the saved copy. Your MDSPs (system prompts) and LLM settings are also stored in this folder; an exported settings file includes them but never your conversations. The name of the settings file you last imported or exported (only the file name, not its folder) is kept there too, to show it on screen. Your inference presets (sampling settings, stop sequences and their links to MDSPs and model file names) are stored there too and are included in an exported settings file. Your text shortcuts (each shortcut and the text it expands to) are stored there too and are included in an exported settings file; “Export shortcuts” saves them in a file only when you press it, where you choose, and never with your editor text or conversations. Before you import shortcuts, a backup of your current shortcuts is saved in this folder (the newest 5 are kept). Images you add to an LLM message are kept in memory only, are never saved to a file and are never sent anywhere; a kept conversation keeps only their file names. Text files you add become part of the message and are saved only with a kept conversation. A diagnostics log (ttmai_diag.log) is kept in this folder while “Record diagnostics” in Settings > Diagnostics is on (on by default; you can turn it off). It holds this computer's details (Windows or Linux version, processor, memory, graphics cards and their driver versions), the settings, free memory and what the app did (loading models, how long a dictation took and how many characters it gave, LLM answer speed and errors), never your editor text, speech, conversations, MDSPs or shortcut texts. Folder paths in it are written without your user name, and only the newest 2,000 lines are kept. It is never sent anywhere; it leaves your computer only if you press Copy and paste it somewhere yourself, for example into an e-mail when you ask for help. Clear deletes it. If a native error ends the app, one line about it (no text of yours) is written to ttmai_native_last.txt in the same folder and moved into the log at the next start. Settings > Reset deletes the settings in this folder and, if you tick them, the word lists, MDSPs, inference presets, text shortcuts and the kept conversation and editor text; it does not delete model files, the diagnostics log or files you exported. Uninstalling the app removes the data in the app's folder.
  5. Speech models. The speech recognition models included with the app, and any model files you add yourself, are used only on your computer. The same applies to language model files (for example GGUF files and their image input files) that you download and load yourself; each keeps its own licence. The app does not download anything.
  6. No tracking. There is no analytics, advertising, telemetry or crash-reporting service.
  7. Children. The app does not collect information from anyone, including children.
  8. Changes. If this policy changes, the new version is published on this page with a new effective date.
  9. Contact. For questions about this policy, write to the contact address above.
